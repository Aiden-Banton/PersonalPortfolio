# JNCIA-102 — Answer key

**Routing Tables, Preference and Routing Instances**

Look at this after you have attempted the lab, not before. Working the lab and then
marking yourself against this is worth several times more than reading it first.

## Status

Not yet written. This key gets filled in when the lab is first run — the expected output
sections should contain *real* captured output from that run, not output written from
memory of what the commands print.

That ordering is deliberate. An answer key written before the lab has been executed is a
prediction, and predictions in answer keys are how labs end up confidently wrong.
